Our vision

One grid for safer Indian city life

Built for the road that actually breaks

Western map apps assume smooth lanes and clean markings. We build for the other case: the unmarked stretch, the sudden hole, the scooter that needs a side warning — photo evidence and a shared pin, not a polished demo city.

A network that compounds

Every confirmed report makes the map richer for the next rider. Parking, trip warn, and civic briefs sit on the same grid — a public good that gets stronger as citizens and local businesses join.

About us

The shared layer for Indian city life

City Grid is an independent Android app. Citizens file photo-and-GPS reports of road hazards; the live map and trip mode warn the next rider. From those reports we can build a civic brief — severity, hotspots, sample photos, map links — for municipal and IAS conversations. We are not affiliated with, endorsed by, or operated by any municipal corporation.

Parking is part of the citizen account on Discover. More city tools come next — same grid, same login. Deepest coverage today: Bengaluru and Durgapur, with pan-India reporting supported.
